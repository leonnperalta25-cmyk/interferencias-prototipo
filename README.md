# Prototipo: Solicitud de Interferencias sin papel

Prototipo de una propuesta interna del Sector Técnico del Servicio Eléctrico Villa La
Angostura (EPEN) para pedir y responder por internet la Solicitud de Interferencias.

**No es un servicio oficial de EPEN.** Los datos son de ejemplo, quedan guardados solo en
el navegador de quien lo prueba y nada se envía a EPEN ni a ningún correo.

Para recorrerlo: https://leonnperalta25-cmyk.github.io/interferencias-prototipo/
(arriba de todo, «Cómo recorrerlo»).
